## Custom maps

`opent5 convert` turns a map built with the PC Mod Tools into a PS3 map zone,
either replacing a stock map or under its own name with its own files. A
converted map carries its own lighting (lightmaps, light grid, reflection
probes), its own compass, its own materials and textures (including art that
exists in no stock zone), static-model props, and the objective entities every
multiplayer gametype needs. Stock zones and paks are never modified: everything a
map needs lives in its own files.

## Editing

- Nested struct fields are editable in the app and the command line.
- Streamed textures can be replaced at a different size, not only the same size.
- `replace --allow-shared` edits images whose data lives in a shared pak, with a
  clear warning.

## Known limits

Some converted-map details still need confirming on hardware: the brightness of a
converted map's light grid, and two multiplayer modes (Search and Destroy icons,
Domination start). These are documented in docs/convert.md and the demo notes.

Edited zones keep the original console signature, which no longer matches, so
they load only on a client with the signature check patched out.
