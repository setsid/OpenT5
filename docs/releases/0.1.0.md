The first release.

**Zones.** Every Black Ops PS3 zone on the disc, the title update and DLC 1 to 5
(178 in total) opens, parses down to the last byte and rebuilds byte for byte.

**Editing.**
- Scripts, cfg files, menus, string tables, localised text and the map entity
  string can be any length. Pointers, block sizes and headers are recomputed on
  save.
- When a string is shared between keys, OpenT5 asks whether to edit them all or
  split off the one you picked.
- Images can be replaced, including those streamed from `.pak` files.
- Struct fields can be edited through the fields view. Counts and pointers stay
  locked.
- GSC scripts show with their indentation restored and save back exactly as the
  game stores them.

**Desktop app.**
- Zone tree, code editor, string table grid, image viewer and wireframe
  geometry viewer, plus hex and fields views.
- Search, undo and redo, and a changes panel.
- Save As with verification, and a command palette.

**Command line.** `info`, `list`, `extract`, `replace`, `unpack`, `pack`, `verify`,
`rebuild` and `convert`, all with `--json`.

**Custom maps (early).** `opent5 convert` turns a map built with the PC Mod Tools
into a PS3 map zone. A sealed test room has loaded and played in RPCS3. Lighting,
the compass and map registration are still being worked on.

**Updates.** The app checks this repository's releases on start and offers a
restart once a new version has been downloaded and its signature verified. You
can turn this off in the Help menu.

Edited zones keep the original console signature, which no longer matches, so
they load only on a client with the signature check patched out.
